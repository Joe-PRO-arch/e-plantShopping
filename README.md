# e-plantShopping

Paradise Nursery is a plant shopping web application built with React and Redux Toolkit.
Repository name: `e-plantShopping`.

## Overview
- Landing page: background image, company name, short presentation and a "Get Started" button.
- Product list page: 30 houseplants in 5 categories (name, image, description, price, "Add to Cart").
  The button is disabled and renamed "Added to Cart" once the plant is in the cart.
- Header: links to Home, Plants and Cart, with a cart icon showing the total number of items in real time.
- Cart page: thumbnail, unit price, quantity (+ / -), subtotal per plant, delete button,
  total number of plants, total amount, "Continue Shopping" and "Checkout" (coming soon).

## Tech stack
React 18, Redux Toolkit, React-Redux, Vite, GitHub Pages (gh-pages).
